# ReactJS Learning Project 🚀

This project is made for learning and practicing important ReactJS concepts in a simple way.  
All concepts are explained with working examples so beginners can easily understand React.

---

## 📚 Topics Covered

### React Basics
- JSX
- Components
- Props
- Event Handling

### React Hooks
- useState
- useEffect
- createContext
- useContext

### Array Methods
- map()
- filter()

### Routing
- BrowserRouter
- Routes
- Link
- Navigation
- useLocation
- useParams

### Forms & API
- Form Handling
- API Fetching
- API Error Handling
